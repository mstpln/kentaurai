Implement a realistic, fully interactive mock-data environment for KentaurAI's existing Replit Live Preview.

## Goal

Enable frontend development across the existing KentaurAI application using synthetic data, without connecting to production Cloudflare resources.

## Requirements

1. Preserve the existing HTML, CSS, JavaScript, navigation, and visual design. Do not rebuild or redesign the application.

2. Populate the existing local D1 database with realistic synthetic data covering:

   * Horses, trainers, drivers, and tracks
   * Race meetings, races, and results
   * Historical statistics and trends
   * Form, top speed, and race scenarios
   * Analysis views and filters
   * Relevant settings and workflow statuses

3. Ensure the main pages and detail views are interactive, including navigation, tabs, filtering, searching, and expanding content.

4. Include representative edge cases such as long names, missing statistics, empty states, different race distances, and varying amounts of historical data.

5. Reuse existing database schemas, application logic, and UI components wherever possible. Avoid duplicating the frontend or building a separate mock application.

6. Keep all synthetic data clearly isolated from production. Do not use production credentials, remote D1/R2 bindings, or real external API calls.

7. Make the mock data reproducible and easy to reset or regenerate, ideally through a simple Replit development workflow.

8. Keep the implementation lightweight. Do not build unnecessary synchronization infrastructure or modify production behavior.

## Quality assurance

* Verify that all important frontend screens render with realistic data.
* Test navigation, filters, search, and interactive components.
* Run relevant existing tests.
* Confirm that Live Preview and automatic reload still work.
* Verify that production remains completely untouched.

## Final review

Review the implementation and fix any blocking issues.

Report:

* Which pages and features are covered.
* Any remaining limitations.
* Test results.
* Whether Live Preview is ready for normal frontend development.

**Important:** Work on a dedicated development branch. Do not push, merge, publish, deploy, or modify Cloudflare production. Keep all changes local until I approve them.
